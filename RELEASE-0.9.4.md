# MarketSync 0.9.4

This prerelease updates MarketSync for the current Forever 1.60.1 client (build 70205).

## Changes since 0.9.3

- Added Forever interface `16001` to the TOC to clear the incompatible-addon warning.
- Removed the global alert-discount sliders from Settings. Individual alert thresholds remain editable, including the below-market preset in the Alerts editor.

Processing and Alerts remain opt-in beta features. This build targets Forever; other declared WoW client versions have not been validated for this prerelease.
