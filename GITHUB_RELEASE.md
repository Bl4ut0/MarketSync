# MarketSync 0.9.7-rc1

Release candidate for Forever playset synchronization and enhanced Classic list searches. Auctionator is optional.

- Fixed guild discovery and price transfers between numbered Forever partitions of the same playset, while retaining separate playsets and full character identities.
- Enhanced Classic Search now collects shopping-list and craft-material results in one table, retaining source-page purchase verification.
- Added Forever beta support to the local deployment script.

Both guild members should update and reload before testing. Report missing peers, incomplete transfers, purchase verification issues, or Lua errors with the client build and realm names.

See [release notes](https://github.com/Bl4ut0/MarketSync/blob/v0.9.7-rc1/RELEASE-0.9.7-rc1.md) and [full changelog](https://github.com/Bl4ut0/MarketSync/compare/v0.9.6...v0.9.7-rc1).
